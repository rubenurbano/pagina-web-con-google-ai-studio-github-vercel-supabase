🚀 Crea y publica tu propia web con base de datos, gratis

Guía paso a paso para principiantes absolutos con Google AI Studio, GitHub, Vercel y Supabase.

ℹ️Para quién es esta guía. Para cualquier persona, sin necesidad de saber programar ni de haber usado antes ninguna de estas herramientas. Todo se explica desde cero, con palabras sencillas. Si algo te suena a chino, no te preocupes: cada concepto nuevo se explica cuando aparece y hay un glosario al final.

🌐 Una web publicada

Una página web profesional en internet, con su propia dirección (por ejemplo https://tu-proyecto.vercel.app).

📝 Un formulario funcional

Un formulario de contacto que guarda en una base de datos los datos de las personas que lo rellenan.

🤖 Mejoras con IA

Un sistema para modificar tu web con inteligencia artificial y que los cambios se publiquen solos.

💸 Coste cero

⏱️ Tiempo estimado

Entre 2 y 4 horas la primera vez, con calma. Puedes parar al final de cualquier paso y retomarlo otro día.

❗Lee esto antes de empezar (2 minutos). Hay tres cosas del mundo real que conviene saber desde el principio:

  1. Vercel (plan gratuito Hobby) es solo para uso personal y no comercial. Según las normas de Vercel, se considera comercial cualquier web publicada con el fin de obtener un beneficio económico. Nuestro ejemplo (la web de una consultoría) sirve para aprender y practicar. Si vas a usarla para captar clientes de un negocio real, necesitarás el plan de pago de Vercel u otro servicio de hosting cuyas condiciones lo permitan.

📚 Conceptos previos

Antes de tocar nada, entender qué vamos a construir y por qué con estas cuatro herramientas.

1. ¿Web estática o web dinámica?

Web estáticaWeb dinámica (con base de datos)
Qué es Una página que siempre muestra lo mismo a todo el mundo. Una página que puede recibir, guardar y mostrar información que cambia.
Ejemplo cotidiano Un folleto impreso: lo lees, pero no puedes escribir en él. Un libro de visitas: la gente deja sus datos y quedan guardados.
¿Puede guardar datos de visitantes? No Sí
Ejemplo Una página con tu presentación. Una web con formulario de contacto cuyos mensajes llegan a una tabla.

Nuestra web será dinámica: cuando alguien rellene el formulario, sus datos viajarán por internet hasta una base de datos (una especie de hoja de cálculo gigante y segura en la nube) donde tú podrás consultarlos.

2. Las 4 herramientas y qué hace cada una

Imagina que estás montando una tienda:

HerramientaQué haceAnalogía
Google AI Studio Diseña la web y escribe el código por ti a partir de lo que le pidas con texto. El arquitecto que dibuja los planos.
GitHub Guarda el código en la nube, con historial de todos los cambios. El archivo donde se guardan los planos de forma ordenada y segura.
Vercel Publica la web en internet y la mantiene en línea. El local comercial donde los clientes entran a ver tu tienda.
Supabase Guarda en una base de datos la información que envían los visitantes. El buzón con archivador donde llegan y se guardan los mensajes.

3. Esquema del flujo de trabajo

[ FLUJO DEL CÓDIGO ] Google AI Studio ──(envía el código)──> GitHub (repositorio privado) ▲ │ │ (pides correcciones │ (despliegue automático) │ con texto) ▼ └────────────────────────────── Vercel (la web en internet) │ │ (conexión con claves guardadas │ como variables de entorno) [ FLUJO DE LOS DATOS ] ▼ Visitante (rellena el formulario) ────────> Supabase (base de datos)

Cómo leer el esquema:

  1. Desarrollo: el código se crea en Google AI Studio y se envía a GitHub.
  2. Publicación: Vercel vigila GitHub; cuando hay cambios, actualiza la web pública sola.
  3. Datos: cuando un visitante rellena el formulario, los datos viajan a Supabase usando la URL del proyecto y una clave pública que guardas en Vercel como variables de entorno.

Paso 0: Prepara tus cuentas gratuitas

⏱️ 15-20 min

Necesitas cuatro cuentas gratuitas. Para simplificar, usaremos tu cuenta de Google y tu cuenta de GitHub para entrar en las demás, de modo que no tengas que recordar muchas contraseñas.

Paso 0.1: Cuenta de Google (Gmail)

  1. Si ya tienes Gmail, pasa al siguiente paso.
  2. Si no, entra en https://accounts.google.com/signup y sigue las instrucciones.
  3. Anota tu correo y tu contraseña en un lugar seguro.

Paso 0.2: Cuenta de GitHub

  1. Entra en https://github.com y pulsa Sign up (Registrarse).
  2. Escribe tu correo, crea una contraseña y elige un nombre de usuario (por ejemplo maria-garcia-web). Piensa que puede aparecer en tus direcciones web.
  3. Resuelve la verificación que te pidan y confirma tu correo con el código que recibirás.

Paso 0.3: Cuenta de Vercel

  1. Entra en https://vercel.com y pulsa Sign Up.

Paso 1.2: Escribe el prompt inicial

¿Qué es un prompt? Es el texto con el que le explicas a la inteligencia artificial lo que quieres. Cuanto más claro y detallado, mejor resultado.

❗Por qué este prompt incluye «requisitos técnicos». Google AI Studio puede crear aplicaciones con una parte de servidor (backend). Para publicar tu web de forma sencilla y gratuita en Vercel, necesitamos una web solo de «frontend». Por eso lo pedimos de forma expresa.

📋 Prompt para copiar — Prompt inicial de la landing page
Crea una landing page moderna, profesional y responsive (que se vea bien en móvil y en ordenador) en español para una consultoría de automatización e inteligencia artificial para empresas llamada "AutoIA Consultoría".

Requisitos técnicos:
- Crea una aplicación SOLO de frontend con React y Vite, que se pueda publicar como sitio estático. No crees servidor ni backend propio.
- No uses la API de Gemini ni ninguna otra API de inteligencia artificial dentro de la web.
- No incluyas inicio de sesión ni cuentas de usuario.

La página debe tener estas secciones:
1. Cabecera con el nombre de la empresa y un menú sencillo.
2. Sección principal (hero) con un titular potente, un subtítulo explicativo y un botón de llamada a la acción.
3. Sección de servicios con 3 tarjetas (por ejemplo: automatización de procesos, chatbots con IA, análisis de datos).
4. Sección de beneficios o "por qué elegirnos".
5. Un formulario de contacto visual con estos campos:
   - Nombre
   - Apellido
   - Teléfono
   - Correo electrónico
   - Tamaño de la empresa (lista desplegable: 1-10 empleados, 11-50, 51-200, más de 200)
   - Área de interés (lista desplegable: Automatización de procesos, Chatbots con IA, Análisis de datos, Formación, Otro)
   - Botón de enviar con el texto "Solicitar consultoría gratuita"
6. Un pie de página con datos de contacto ficticios.

Estilo: diseño limpio, mucho espacio en blanco, tipografía moderna y colores profesionales. Por ahora el formulario solo debe validar los campos y mostrar un mensaje de "Gracias, te contactaremos pronto" al enviarlo (aún no está conectado a ninguna base de datos).

La IA tardará unos instantes. Verás dos zonas importantes:

  • Vista previa (Preview): cómo se ve tu web.
  • Código (Code): los archivos creados. No necesitas entenderlos ni tocarlos.

Paso 1.3: Refina el diseño conversando

Ahora pide cambios, de uno en uno o en pequeños grupos, escribiendo en el mismo chat.

📋 Prompt para copiar — Cambiar los colores
Cambia la paleta de colores: usa tonos azul marino y blanco como base, con detalles en gris claro. Mantén un aspecto sobrio y profesional.
📋 Prompt para copiar — Poner los botones en verde
Haz que todos los botones principales sean de color verde (un verde vivo pero elegante), con texto blanco, esquinas redondeadas y un efecto suave al pasar el ratón por encima.
📋 Prompt para copiar — Cambiar la ubicación del formulario
Mueve el formulario de contacto a la parte superior de la página, en la sección principal, situado a la derecha del titular. En móvil, que aparezca justo debajo del titular.
📋 Prompt para copiar — Ajustar los titulares
Cambia el titular principal por: "Automatiza tu empresa con inteligencia artificial". Cambia el subtítulo por: "Ahorra tiempo, reduce costes y haz crecer tu negocio con soluciones a medida. Cuéntanos tu caso y te asesoramos sin compromiso."

Paso 4.2: Crea la tabla con el SQL Editor

Qué es SQL: el lenguaje que entienden las bases de datos. Copia, pega y ejecuta.

  1. En el menú lateral de Supabase, pulsa SQL Editor.
  2. Pulsa New query.
  3. Copia y pega todo este bloque:
📋 Prompt para copiar — Consulta SQL para crear la tabla registros
-- 1) Crear la tabla "registros" (si todavía no existe)
create table if not exists public.registros (
  id uuid primary key default gen_random_uuid(),
  nombre text not null check (char_length(nombre) between 1 and 100),
  apellido text not null check (char_length(apellido) between 1 and 100),
  telefono text check (telefono is null or char_length(telefono) <= 30),
  correo text not null check (char_length(correo) between 5 and 200),
  tamano_empresa text check (tamano_empresa is null or char_length(tamano_empresa) <= 50),
  area_interes text check (area_interes is null or char_length(area_interes) <= 100),
  fecha timestamptz not null default now()
);

-- 2) Activar la seguridad por filas (RLS)
alter table public.registros enable row level security;

-- 3) Dar permiso a la web (rol "anon") para INSERTAR filas, y solo eso
grant insert on public.registros to anon;

drop policy if exists "Permitir insertar desde la web" on public.registros;
create policy "Permitir insertar desde la web"
  on public.registros
  for insert
  to anon
  with check (true);
  1. Pulsa Run (o Ctrl + Enter).
  2. Debe aparecer Success. No rows returned.

Editor SQL con el código de la tabla registros. Resaltar el botón Run.

¿Qué hace cada parte del SQL?

  • Parte 1: crea la tabla. not null significa «campo obligatorio». Las comprobaciones check limitan la longitud de los textos.
  • Parte 2: activa RLS (Row Level Security). Nadie puede tocar la tabla sin permiso expreso.
  • Parte 3: da permiso a los visitantes para insertar filas, pero no para leer, modificar ni borrar.

❗Nota sobre los permisos: desde 2026, las tablas nuevas de Supabase no son accesibles desde la web automáticamente: hace falta un permiso expreso, que es la línea grant insert … to anon. Si te la saltas, el formulario fallará con «permission denied».

❗Tú sí podrás ver todos los registros desde el panel de Supabase (en Table Editor), porque entras como administrador. Los visitantes de la web, no.

Paso 4.3: Comprueba que la tabla existe

  1. En el menú lateral, entra en Table Editor.
  2. Debes ver la tabla registros con sus columnas, todavía vacía.
  3. Fíjate en que aparece una indicación de que RLS está activado.

Paso 4.4: Localiza la URL y la clave pública

La web necesita dos datos para «llamar a la puerta» de tu base de datos:

  • Project URL: la dirección de tu proyecto (algo como https://abcdefghijk.supabase.co).
  • Clave pública (publishable key): empieza por sb_publishable_….

ℹ️Un cambio de nombre importante. Hasta hace poco, esta clave se llamaba anon key. Supabase la está sustituyendo por la publishable key y tiene previsto retirar las antiguas a finales de 2026. Cumplen el mismo papel.

Cómo encontrarlas:

  1. Opción rápida: pulsa el botón Connect en la parte superior del proyecto.
  2. Opción por menús: abre Project Settings (engranaje).
    • En Data API encontrarás la Project URL.
    • En API Keys, pestaña Publishable and secret API keys, copia la Publishable key.
  3. Pega ambos datos en tu ficha del proyecto.

Paso 5: Conecta la web con la base de datos de forma segura

⏱️ 30-40 min

Tenemos una web publicada y una base de datos lista, pero no se conocen entre sí. Vamos a conectarlas en tres partes:

  1. Pedir a AI Studio que programe el envío del formulario a Supabase.
  2. Guardar la URL y la clave en Vercel, como variables de entorno.
  3. Volver a publicar y comprobar que no hay claves escritas en el código.

Paso 5.1: Por qué NO se pegan las claves en el código

  • El código vive en GitHub; si lo haces público, cualquier clave quedaría expuesta.
  • Los bots rastrean GitHub constantemente buscando claves filtradas.
  • Si una clave se filtra, hay que cambiarla y modificar el código otra vez.

La solución son las variables de entorno (environment variables): datos guardados en el servicio de hosting (Vercel), fuera del código.

🔒Regla de oro: ninguna clave, contraseña o secreto debe aparecer escrita en el código ni en los mensajes que envías a AI Studio.

ℹ️Un matiz para entenderlo bien. En una web, el navegador del visitante necesita la URL y la clave pública para poder enviar los datos, así que esos dos valores acaban siendo visibles en el código que descarga el navegador. Eso es normal y está previsto por Supabase. Lo que protege tu base de datos no es esconder esa clave, sino las reglas RLS y los permisos del Paso 4.

Paso 5.2: Pide a AI Studio que conecte el formulario con Supabase

Vuelve a Google AI Studio, abre tu proyecto y envía este prompt:

📋 Prompt para copiar — Conectar el formulario con Supabase
Conecta el formulario de contacto con una base de datos Supabase usando la librería oficial @supabase/supabase-js.

Requisitos:
1. Instala/usa @supabase/supabase-js y crea un cliente de Supabase en un archivo aparte (por ejemplo src/supabaseClient).
2. NO escribas ninguna URL ni clave directamente en el código. Lee los valores desde variables de entorno: import.meta.env.VITE_SUPABASE_URL y import.meta.env.VITE_SUPABASE_PUBLISHABLE_KEY.
3. Al enviar el formulario, inserta una fila en la tabla "registros" con estas columnas: nombre, apellido, telefono, correo, tamano_empresa, area_interes. (Las columnas "id" y "fecha" se rellenan solas.)
4. Usa solo la operación de insertar. No pidas que se devuelvan los datos insertados (no uses select después de insert) ni intentes leer la tabla.
5. Mientras se envía, deshabilita el botón y muestra "Enviando…". Si todo va bien, muestra un mensaje de éxito y vacía el formulario. Si hay un error, muestra un mensaje amable en español indicando que se vuelva a intentar.
6. Si faltan las variables de entorno, muestra un aviso claro en la consola del navegador.
7. Mantén la aplicación como solo de frontend (sin servidor ni backend propio).

ℹ️Es posible que en la vista previa de AI Studio el formulario muestre un error de conexión. Es normal: las variables solo las vamos a configurar en Vercel. La prueba real se hará en tu web publicada.

Paso 5.3: Envía los cambios a GitHub

  1. Cuando la IA termine, abre el icono de GitHub en AI Studio.
  2. Envía los cambios (push) al repositorio existente autoia-consultoria.
  3. Comprueba en GitHub que hay un commit nuevo.
  4. En Vercel, la pestaña Deployments mostrará un despliegue nuevo.

Paso 5.4: Configura las variables de entorno en Vercel

  1. En Vercel, abre tu proyecto autoia-consultoria.
  2. Entra en la pestaña Settings.
  3. En el menú lateral, pulsa Environment Variables.
  4. Añade la primera variable:
    • Key: VITE_SUPABASE_URL
    • Value: tu Project URL de Supabase.
    • Environments: deja marcados Production, Preview y Development.
    • Pulsa Save.
  5. Añade la segunda variable:
    • Key: VITE_SUPABASE_PUBLISHABLE_KEY
    • Value: tu clave pública (sb_publishable_…).
    • Pulsa Save.

  3. Pulsa los tres puntos (⋯) y elige Redeploy.

  1. En GitHub, abre tu repositorio y busca el archivo del cliente de Supabase.
  2. Comprueba que solo aparecen referencias del tipo import.meta.env.VITE_… y ninguna dirección https://…supabase.co ni claves que empiecen por sb_.
  3. Si ves una clave escrita, pide a AI Studio: «Quita las claves del código y léelas desde variables de entorno», envía los cambios y genera claves nuevas en Supabase.

  • Tras el Redeploy sigue sin conectar: comprueba que las variables están guardadas para Production.
  • Vercel no me deja guardar la variable: revisa que no hay espacios al principio ni al final.

Paso 6.4: Protege el formulario contra el spam básico

📋 Prompt para copiar — Medidas básicas contra el spam
Añade medidas básicas contra spam al formulario de contacto:
1. Un campo oculto "trampa" (honeypot) llamado "sitio_web" que las personas no ven. Si viene relleno, no envíes nada a Supabase y muestra igualmente el mensaje de éxito.
2. Validación del formato del correo electrónico y de la longitud máxima de cada campo (nombre y apellido: 100 caracteres; teléfono: 30; correo: 200).
3. Tras un envío correcto, bloquea el botón durante 30 segundos para evitar envíos repetidos.
No cambies el diseño ni el resto del funcionamiento.

ℹ️Estas medidas detienen solo los programas automáticos más simples. Si algún día recibes mucho spam, se pueden añadir sistemas más avanzados (CAPTCHA).

Ejercicio 3 — Provoca un error a propósito y arréglalo

Aprender a usar la consola del navegador y el ciclo de corrección.

Preguntas frecuentes

¿Necesito saber programar?

No. Toda la programación la hace Google AI Studio a partir de tus instrucciones en español. Tú solo copias y pegas datos en formularios web.

¿Cuánto cuesta esto realmente?

Cero euros mientras uses los planes gratuitos de las cuatro herramientas. Solo pagarías si compras un dominio propio (opcional, unos 10-15 € al año) o si pasas a un plan de pago de Vercel o Supabase por superar los límites o por uso comercial.

¿Puedo usar la web para mi negocio?

Con el plan Hobby de Vercel, no: es solo para uso personal y no comercial. Para un negocio real necesitas el plan de pago de Vercel u otro hosting cuyas condiciones lo permitan.

¿Qué pasa si Supabase pausa mi proyecto?

No se pierde nada. Entras en el panel, abres el proyecto y pulsas Resume project. En unos minutos vuelve a funcionar con todos los datos intactos.

¿Puedo cambiar la web sin saber nada de código?

Sí. Escribes lo que quieres en el chat de AI Studio, envías los cambios a GitHub y Vercel publica la versión nueva automáticamente.

¿Qué pasa si rompo algo?

Nada grave. GitHub guarda el historial completo y Vercel mantiene la última versión que funcionaba. Puedes pedir a AI Studio que deshaga cambios o volver a una versión anterior.

¿Por qué mi formulario no guarda datos aunque todo parezca bien?

Casi siempre es una de estas tres cosas: (1) falta el permiso grant insert … to anon, (2) falta la política RLS, o (3) las variables de entorno en Vercel están mal escritas o falta el Redeploy. Revisa los pasos 4.2 y 5.4-5.5.

¿Puedo ver los datos desde fuera de Supabase?

Sí. En Supabase puedes exportar la tabla a CSV. También puedes pedir a AI Studio que cree un panel privado, aunque eso ya requiere más configuración y no está cubierto en esta guía.

TérminoExplicación sencilla

Backend (servidor)La parte que trabaja «detrás», en un ordenador remoto. En esta guía no la necesitamos.

React / ViteHerramientas de programación con las que se construye la web. No necesitas manejarlas.

HostingEl servicio que mantiene tu web publicada y accesible desde internet.

CachéCopia guardada por el navegador para cargar más rápido; a veces muestra versiones antiguas.
DominioEl nombre de tu web (por ejemplo, miempresa.com).

Ideas para seguir avanzando

  • Añadir más secciones: preguntas frecuentes, testimonios, blog.

  • Añadir un sistema anti-spam más avanzado (CAPTCHA).
  • Conectar un dominio propio y mejorar el posicionamiento en buscadores (SEO).
